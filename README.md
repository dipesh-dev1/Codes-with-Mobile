# Codes with Mobile

A collection of programs and code snippets written and practiced on a mobile phone. This repository shows that you can learn and practice programming anywhere, even without a laptop, using just a phone and a code editor or terminal app.

## About this repository

- Programs written, tested, and saved directly from a mobile device
- Beginner-friendly practice code, kept simple and easy to read
- A growing collection that is updated as I learn and practice more

## Working with code on mobile

If you want to code on your phone too, here are some common options:

- **Android:** apps such as Termux (terminal), or editors and IDEs from the Play Store
- **iOS:** code editor and Python or JavaScript apps from the App Store
- **Any phone:** online editors and compilers that run in the browser

## Getting started

### Clone the repository

```bash
git clone https://github.com/dipesh-dev1/Codes-with-Mobile.git
cd Codes-with-Mobile
```

### Run a program

Open any file and run it with the tool for its language.

On a phone, you can also open the file in your code editor app and use its built-in run option.
